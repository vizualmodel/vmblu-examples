# DataCenter

## Node



## Pins

### policy.query

Returns authorization facts owned by the data center, such as assignment or access-record information.

### data.query

Returns the result of an approved data query directly to the policy enforcer.

### data.operation

Performs an approved data operation against the synthetic patient records.

### admin.query

Returns data center information for an approved admin query.

### admin.operation

Performs an approved admin operation against data center state.

### event.record

Emits data-access evidence such as reads, writes or rejected internal data operations.
