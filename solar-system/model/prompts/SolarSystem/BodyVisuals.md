# BodyVisuals

## Node

Builds and updates visual representations of bodies, labels, and lighting-related scene patches.

## Pins

### scene.body-poses

Receives current celestial body poses.

### scene.command

Receives solar-system visual commands such as scale or label toggles.

### scene.camera

Receives camera state used for view-dependent visual updates.

### scene.updates

Emits scene patch updates produced by this subsystem.

### scene.animatables

Emits animatable registrations for the animator.
