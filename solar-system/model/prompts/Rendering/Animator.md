# Animator

## Node

Applies time-based updates to registered animatable objects using simulation ticks.

## Pins

### anim.scene-patches

Emits scene patches generated by animation updates.

### anim.tick

Receives simulation ticks that drive animation updates.

### anim.registry

Receives the current set of animatable objects to manage.

### anim.body-poses

Receives body poses used to update animations tied to celestial bodies.
