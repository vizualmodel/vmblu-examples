# CameraManager

## Node

Creates and updates cameras, including body-relative views and flyby motion.

## Pins

### camera.command

Receives a camera placement or movement command.

### ol/



### camera.body-poses

Receives body poses used to resolve body-relative cameras.

### camera.layout

Receives layout updates that can affect camera aspect or controls.

### camera.active

Emits the currently active camera state.

### camera.event

Emits semantic camera changes for agent observation.
