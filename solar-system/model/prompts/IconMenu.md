# IconMenu

## Node

Provides a compact icon menu to open or control overlays such as the chat panel.

## Pins

### ui.command

Emits a normalized command generated by a UI interaction.

### ui.panel

Receives commands that show or hide a user interface panel.

### camera.state

Receives the active camera state and available camera list for the settings menu.

### sim.state

Receives the current simulation state for display or controls.
