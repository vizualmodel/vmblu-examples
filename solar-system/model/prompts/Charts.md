# Charts

## Node

Composes analytical chart nodes that generate on-demand chart overlays.

## Pins

### chart.command

Receives chart requests such as show, hide, or update chart parameters.

### chart.overlay

Emits the current chart overlay payload for display.

### sim.body-poses

Receives current body poses for computation or rendering support.

### sim.tick

Receives simulation ticks used to update local state.
