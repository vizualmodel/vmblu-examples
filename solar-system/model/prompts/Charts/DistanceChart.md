# DistanceChart

## Node

Calculates and packages chart data such as distances between selected celestial bodies.

## Pins

### chart.command

Receives chart requests such as show, hide, or update chart parameters.

### chart.body-poses

Receives body poses used to compute chart values.

### chart.tick

Receives simulation ticks to sample chart values over time.

### chart.overlay

Emits the current chart overlay payload for display.
