# vmblu Project

Use `solar-system.blu` as the project entrypoint.

The model file set lives in `model/`.
Node implementations live in `nodes/`.

This project uses the `rt-agent` runtime. Agent interaction is handled through
the runtime tool broker and generated capability manifest.

General vmblu instructions come from the installed vmblu skill/plugin/CLI docs,
not from copied files in `.vmblu/`.
